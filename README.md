# PluginLampa — видеоисточники для Lampa

Публичная установочная сборка PluginLampa **v0.5.0**. Один JavaScript-файл, никаких дополнительных загрузок из приватного репозитория.

## Установка в Lampa

1. Откройте **Настройки → Расширения / Плагины → Добавить** (название пункта может отличаться в разных версиях Lampa).
2. Вставьте адрес плагина:
   
   ```text
   https://cdn.jsdelivr.net/gh/ASarych/PluginLampa-public@main/PluginLampa.js
   ```
3. Подтвердите установку, при необходимости перезапустите Lampa.
4. Откройте карточку фильма и вызовите контекстное меню → **«Найти видео (Video Finder)»**.

**Альтернативный прямой адрес** (если CDN не доступен):

```text
https://raw.githubusercontent.com/ASarych/PluginLampa-public/main/PluginLampa.js
```

## Возможности

- **Internet Archive:** поиск записей в публичном каталоге и воспроизведение прямых MP4.
- **Rutube:** поиск полнометражных роликов и получение HLS при выборе видео. Доступность зависит от Rutube, CORS и устройства.
- **Stremio:** можно добавить совместимое расширение через пункт **«Stremio · расширения»** в меню результатов. Поддерживаются прямые HTTP(S)-потоки; торрент-источники, внешние веб-страницы и DRM не поддерживаются.
- Сохранение результатов поиска на устройстве и обновление по запросу; исключение неисправных источников на время.

## Статус

Автоматические тесты сборки выполнены в исходном приватном проекте; **запуск на настоящем телевизоре и воспроизведение из интернета ещё не подтверждены**. Не гарантируется наличие определённого фильма или доступность источника.

Этот репозиторий содержит только распространяемую JS-сборку; оригинальные серверные модули Lampac в неё **не включены**.
