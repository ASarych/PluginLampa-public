# Текущая версия: PluginLampa 0.6.1 (18 октября 2026)

**Ссылка для Lampa (включая Samsung Tizen / Media Station X):**

```text
https://asarych.github.io/PluginLampa-public/tv.js
```

`PluginLampa-tizen.js` — второй адрес той же актуальной сборки; их **не нужно устанавливать одновременно**.

В версии 0.6.1 **все источники опрашиваются по умолчанию**, включая Rutube, Internet Archive и добавленные Stremio-расширения. Для совпадений только по названию добавлена пометка. Пункт **«Диагностика источников»** показывает, был ли запрос, почему источник пропущен, вернул ли пустой ответ или торренты вместо прямых HTTP(S)-видео. Добавление нового расширения Stremio больше не удаляет кэш других источников.

**Ограничения:** многие Stremio-аддоны предоставляют только торренты (`infoHash`), для которых одного клиента Lampa на Tizen недостаточно; они не появятся как прямые видеопотоки. Возможны CORS и другие сетевые ограничения.

Если плагин уже установлен по `tv.js`, достаточно перезапустить Lampa после публикации; ссылки на старые файлы `PluginLampa.js` и `PluginLampa-lite.js` лучше убрать, чтобы исключить конфликт нескольких версий.

> **Samsung Tizen / Media Station X — диагностика ошибки 404 (18 октября 2026).** В версии Lampa 3.x проверка расширений запрашивает файл и ищет текст `Lampa.`. Новые диагностический файл и Tizen-сборка включают этот маркер и используют стандартный `Lampa.Manifest.plugins`.
>
> Для стабильного URL рекомендуется **GitHub Pages**: в [Settings → Pages](https://github.com/ASarych/PluginLampa-public/settings/pages) выбрать `Deploy from a branch`, ветку `main`, папку `/(root)`, сохранить настройки и дождаться надписи `Your site is live at …`.
>
> 1. Удалить из Lampa старые ссылки на `PluginLampa.js` и `PluginLampa-lite.js` (и перезапустить, если потребуется).
> 2. Сначала установить **диагностический** файл: `https://asarych.github.io/PluginLampa-public/PluginLampa-check.js`. Если статус 200 и появляется `PluginLampa CHECK`, загрузка JS работает. Затем диагностический плагин удалить.
> 3. Установить **рабочую Tizen-сборку**: `https://asarych.github.io/PluginLampa-public/PluginLampa-tizen.js`. В ней два адаптера: Internet Archive и Rutube. Без Stremio. Если Pages ещё не включён, оба URL будут недоступны.
>
> У Lampa запросы к внешнему API могут по-прежнему блокироваться CORS, даже если сам JS успешно установлен. Видеовоспроизведение на Tizen ещё не подтверждено.

> ⚠️ **Исправление после ошибки 404 (18 октября 2026):** если Lampa показывает красный восклицательный знак или `404` при загрузке версии 0.5, удалите из списка плагинов старую jsDelivr-ссылку. Для проверки установите отдельную облегчённую сборку 0.5.1:
>
> `https://raw.githubusercontent.com/ASarych/PluginLampa-public/main/PluginLampa-lite.js`
>
> Поддерживаются Internet Archive и Rutube. Stremio временно исключён для диагностики. **Нужно удалить старую запись плагина**, иначе Lampa всё равно будет запрашивать сломанный адрес. Если direct raw не принимается вашим клиентом, включите GitHub Pages (Settings → Pages → Deploy from a branch → main → /root) и используйте `https://asarych.github.io/PluginLampa-public/PluginLampa-lite.js` после успешной публикации. Не вводите ссылку на GitHub `blob`: она ведёт на HTML, а не на JS.

# PluginLampa — видеоисточники для Lampa

Публичная установочная сборка PluginLampa **v0.6.1**. Один JavaScript-файл, никаких дополнительных загрузок из приватного репозитория.

## Установка в Lampa

1. Откройте **Настройки → Расширения / Плагины → Добавить** (название пункта может отличаться в разных версиях Lampa).
2. Вставьте адрес плагина:
   
   ```text
   https://asarych.github.io/PluginLampa-public/tv.js
   ```
3. Подтвердите установку, при необходимости перезапустите Lampa.
4. Откройте карточку фильма и вызовите контекстное меню → **«Найти видео (Video Finder)»**.

**Альтернативный прямой адрес** (если CDN не доступен):

```text
https://raw.githubusercontent.com/ASarych/PluginLampa-public/main/tv.js
```

## Возможности

- **Internet Archive:** поиск записей в публичном каталоге и воспроизведение прямых MP4.
- **Rutube:** поиск полнометражных роликов и получение HLS при выборе видео. Доступность зависит от Rutube, CORS и устройства.
- **Stremio:** можно добавить совместимое расширение через пункт **«Stremio · расширения»** в меню результатов. Поддерживаются прямые HTTP(S)-потоки; торрент-источники, внешние веб-страницы и DRM не поддерживаются.
- Сохранение результатов поиска на устройстве и обновление по запросу; исключение неисправных источников на время.

## Статус

Автоматические тесты сборки выполнены в исходном приватном проекте; **запуск на настоящем телевизоре и воспроизведение из интернета ещё не подтверждены**. Не гарантируется наличие определённого фильма или доступность источника.

Этот репозиторий содержит только распространяемую JS-сборку; оригинальные серверные модули Lampac в неё **не включены**.
